# AquaMarine

Site sobre informações pertinentes ao oceano, desenvolvido em HTML e CSS para o Projeto 1.

## Descrição

A AquaMarine é um site feito para informar e concientizar quem o acessar sobre alguns riscos que o oceano corre e como podemos ajudar
